# 输出契约

## 标准输出

```text
推荐：<最适合平台和达人口吻的发布标题>

备选：
1. <不同机制>
2. <不同机制>
3. <不同机制>

话题建议：#<专项/产品> #<用户场景>
```

## 双平台

```text
抖音
推荐：...
备选：1. ... 2. ... 3. ...
话题建议：...

小红书
推荐：...
备选：1. ... 2. ... 3. ...
话题建议：...
```

## 一条模式

用户说“只给我一个”“直接给标题”时：

```text
<标题>
```

## 缺资料

- 缺脚本：`这次稿件正文还没读到。把脚本、稿件链接或内容梗概发我，我再按平台出标题。`
- 缺平台：`脚本我读到了。这条发抖音还是小红书？`
- 无权限：`这个稿件我现在读不到。请给豆尼访问权限，或把正文贴过来。`
- 链接失效：`这个稿件链接已失效或文档不存在，换一个可访问链接即可。`

## 不要输出

- 评分过程、标题公式名、内部样本排名
- `source_xxx`、记录 token、内部审批词
- 客户、供应商、报价或审核信息
- “保证爆”“必火”等承诺
