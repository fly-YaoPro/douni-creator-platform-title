# 已发布内容标题基准

## 数据使用边界

该基准来自用增部门已发布记录的分层抽样：绝对互动较高、互动率较高以及按平台随机样本。抽样同时查看脚本、粉丝量、公开发布标题和互动数据。

它只能说明不同机制在真实业务里出现过，不能证明标题单独导致播放或互动。不要输出机构、价格、客户反馈等内部字段。

## 被验证过的标题机制

| 机制 | 真实标题特征 | 适合脚本 |
|---|---|---|
| 搜索任务型 | “高中错题本快速整理技巧” | 用户目的明确、教程步骤扎实 |
| 观点型 | “技术平权的时代要来啦” | 达人有鲜明判断，成片以观点推进 |
| 地点行动型 | “跟着…解锁广州宝藏打卡路线” | 城市、旅行、视觉路线与具体动作 |
| 教学产物型 | “制作晶胞可视化模型与互动游戏” | 产物可展示、专业关键词有搜索价值 |
| 结果时间型 | “两周内拿到 offer（附教程）” | 脚本确实包含时间、结果和完整方法 |

## 低稳定性模式

以下写法在普通样本中存在，但不能因为“像爆款”就默认使用：

- “一招教会你”
- “刷不出……试试这招”
- “神仙工作”
- 只有问号、感叹号和情绪，没有具体对象
- 每条都把产品名放在开头

## 结论

1. 好标题不必都夸张。搜索清晰、观点鲜明、结果具体都可能成立。
2. 先保持脚本和达人口吻，再选机制；不能反过来拿公式改造内容。
3. 同一脚本需要平台适配，但核心事实必须一致。
4. 生成结果不能复制样本标题；样本只用于路由和自检。

## 2026-08-24 十条真实发布回测补充

对客户发布表最新 10 条抖音记录做真实作品页与稿件交叉回测后，发现只强调任务名、教程对象和产品词时，标题搜索含义清楚，但容易像功能说明，缺少点击理由。后续抖音推荐标题按以下原则修正：

- 保留一个清晰搜索锚点，不用泛化词替代核心产品或产物。
- 再加入一个脚本可兑现的冲突、反差、结果悬念、数字、意外用途或痛点。
- 噱头来自具体信息，不靠感叹号、“居然”“必看”等空情绪。
- 不能为了加钩子，把脚本没有的收益、身份或结果写进标题。
- “产品 + N 个 Skill + 功能清单”仍属于搜索说明型，不视为完成了噱头优化；推荐标题需进一步形成信息落差。

该回测用于修正生成策略，不代表标题是播放量的唯一原因。
